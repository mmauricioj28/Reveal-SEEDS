# Dashboard-ready EDA tables

Generated by `python -m analysis.eda_trends --run-dir <pipeline run> --output-dir <new directory>`.
Charts are a separate step: `python -m analysis.plot_trends --eda-dir <eda directory> --output-dir <new directory>`.
The pipeline run comes from `analysis.build_safety_dataset`. National source files stay in ignored `data/`.

The tables from the 2026-11-02 run are in [docs/eda_2016_2025](eda_2016_2025/).
The charts are in [docs/figures/weeks5_6](figures/weeks5_6/). Those copies are for review.
Regenerate them from the pipeline rather than editing the files by hand.

All event counts are retained records, not rates and not proof of crash risk.
Census attributes are the current snapshot.

## Grain and keys

| File | Grain | What it counts |
| --- | --- | --- |
| yearly_activity.csv | source, year | matched, unmatched, unidentified, and all retained records |
| monthly_pattern.csv | source, year, month | same split for months that appear in the extract |
| month_of_year.csv | source, month | mean records per calendar day across years that observed that month |
| unobserved_months.csv | source, year, month | months with no retained rows; coverage is `unobserved_not_zero` |
| state_year_activity.csv | source, event_state, year | same split, plus a `geography` label |
| excluded_record_counts.csv | source | one row per source for matched-only comparisons |
| by_fleet_size_matched_only.csv | fleet_bin | matched carrier-years only |
| by_driver_count_matched_only.csv | driver_bin | matched carrier-years only; same bins as fleet size |
| by_carrier_operation_matched_only.csv | carrier_operation | matched carrier-years only |

`source` is `crash` or `inspection`. There is no single primary key across files.
Within each file the grain columns above are the key.

## Column rules

- `matched_records`: usable DOT number found in the census extract.
- `unmatched_records`: usable DOT number absent from the census extract.
- `unidentified_records`: missing or invalid DOT number. These are not part of the unmatched percentage.
- `pct_unmatched_of_linkable` uses matched + unmatched as the denominator.
- `pct_excluded` in `excluded_record_counts` uses all retained records as the denominator. The column `exclusion_denominator` states that.
- `records_per_day` is all retained records divided by the number of calendar days in that month. It is not an exposure rate.
- `month_of_year.mean_records_per_day` averages those calendar-day counts over years in which that month was observed. A year missing that month does not enter the average as zero.
- `yoy_change_pct` is blank unless the previous calendar year is present, its retained count is positive, and both years have all 12 months observed. A partial year is not compared as if it were complete.
- Empty numeric measurements in the pipeline outputs stay null. Fleet and driver bins labeled `missing` are not zeros. A bin labeled `0` is a reported zero.
- `event_state` for crashes is crash-file `STATE` (reported crash location). For inspections it is `REPORT_STATE` (uploading jurisdiction). `geography` repeats that distinction. Neither field is the carrier's `PHY_STATE`.

## Carrier comparisons

`used_in_comparisons_matched` is the only set of events in the fleet, driver, and operation tables.
`excluded_unmatched` and `excluded_unidentified` are the companion counts.
Carrier-years with no retained events are not in these tables. A carrier in the census with no crash is not evidence of safe operation.

`CARRIER_OPERATION` keeps the census codes: A interstate, B intrastate hazardous materials, C intrastate non-hazardous. Unrecognized codes are not recoded.

## Known limitations

The Company Census file is a current snapshot. Grouping a 2016 crash by today's power units does not mean the carrier had that fleet in 2016.
Crash totals after the pipeline are deduplicated on `CRASH_ID`. The source file can contain more than one vehicle row for the same crash.
Months listed in `unobserved_months.csv` were not established as true zero-event months.
Do not label any of these outputs as a crash rate, a safety score, or a causal effect.
